# Literature Matrix

**Project:** Decentralized Graph Navigation: Preventing Action Cycles & Community Trapping Under Partial Observability

| Reader | Paper + link | Claim & evidence | Limitation | Project use |
| :--- | :--- | :--- | :--- | :--- |
| Bartłomiej Jucha | Pisacane et al. (LoG 2024) — *Reinforcement Learning Discovers Efficient Decentralized Graph Path Search Strategies* (GARDEN) ([link](https://arxiv.org/abs/2409.07932)) | **Claim:** Framing decentralized routing as a 1-hop Dec-POMDP under CTDE with a 3-layer GAT + A2C learns useful distance-like node embeddings ("hidden metric space") from local attributes and topology.<br>**Evidence:** Beats heuristic and MLP-RL baselines on 5 SNAP Facebook graphs (148–532 nodes): $R_{\text{trunc}} = 12.6\%\text{–}48.2\%$, $\bar{R}_{\text{oracle}} = 8.74\text{–}16.97$, $R_{\text{win}} = 48.3\%\text{–}60.7\%$; GAT cuts synthetic truncation from $4.32\%$ (MLP) to $1.68\%$. | Strictly **memory-less** (packet carries only target embedding): cannot track failed steps, causing ping-pong loops and community trapping up to $T_{\max} = 100$ (40.1%–48.2% truncation on FB Graphs 4–5). Surpassed in truncation by DistanceWalker on dense synthetic graphs ($\beta \ge 0.5$); evaluated only on static undirected graphs $\le 532$ nodes. | **Core baseline & testbed:** Provides our 1-hop Dec-POMDP environment ($T_{\max}=100$), 80/10/10 target-node split, evaluation metrics, and the memory-less GAT+A2C baseline (GARDEN) plus MLP/heuristic baselines to extend and beat. |
| Bartłomiej Jucha | Shen et al. (NeurIPS 2018) — *M-Walk: Learning to Walk over Graphs using Monte Carlo Tree Search* ([link](https://arxiv.org/abs/1802.04394)) | **Claim:** Pairing a GRU-RNN trajectory encoder with MCTS rollouts and parameter-shared off-policy Q-learning learns multi-step graph walking when rewards are given only at the end.<br>**Evidence:** Reaches $99.0 \pm 1.0\%$ accuracy on Three Glass Puzzle (vs. $49.0 \pm 2.6\%$ REINFORCE), $89.9\%$ MAP on NELL-995 (vs. $87.6\%$ MINERVA), and $43.7\%$ MRR on WN18RR (+4.6–10.9% HITS@1 vs. ConvE on 2–3-hop paths; 1.6–6.0 ms/sample test inference). | Centralized single-agent setup on fully known, deterministic knowledge graphs with known query types (not decentralized 1-hop message passing). Expensive MCTS rollouts (32–128 simulations, 5–14 h training); replacing MCTS with beam search drops puzzle accuracy to $71.7\%$, and missing the target in the MCTS candidate set causes 77.9%–93.3% of failures. | **Sequential memory design:** Inspires our order-based **GRU memory** update ($z_{t+1} = \text{GRU}(z_t, x_{v_{t+1}}^{\text{GAT}})$) carried inside the packet to track step order, recent nodes, and avoid immediate back-and-forth loops (without centralized MCTS). |
| Bartłomiej Jucha | Pándy et al. (LoG 2022) — *Learning Graph Search Heuristics* (PHIL) ([link](https://arxiv.org/abs/2212.03978)) | **Claim:** A recurrent GNN heuristic trained via imitation learning with a shortest-path oracle and order-independent memory of visited nodes predicts distance in $O(1)$ time per step and escapes local traps.<br>**Evidence:** Cuts explored nodes by $58.5\%$ on average vs. SAIL across 8 grid benchmarks ($200\times 200$), beats SOTA by $13.4\%$ on real graphs ($19.5\%$ ex-OGB), stays within $0.3\%\text{–}4.9\%$ of oracle expansions in 3D drone planning, and runs $57.9\%$ faster than BFWS. | Centralized Best-First / A* search maintaining global `OPEN`/`CLOSE` sets and requiring a full-graph shortest-path oracle during training. Batch mean pooling uses a slightly stale memory state within a step, capping sampled neighbors at $n$ trades accuracy for $O(1)$ speed, and the model still occasionally gets stuck in bug-traps or generalizes worse under OGB graph shifts. | **Set-based memory design:** Inspires our **Deep Sets coverage memory** (mean-pooled MLP over visited node embeddings $V_{\text{visited}}$) carried in the packet to avoid re-entering explored communities—plus a sliding-window option (last $W$ nodes) if averaging over long walks blurs older vs. recent visits. |
